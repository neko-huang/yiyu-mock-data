# 益屿平台模拟数据

为 [yiyu-platform](https://github.com/neko-huang/yiyu-platform) 提供本地测试用的模拟用户和活动数据。

## 数据概览

| 类型 | 数量 | 说明 |
|------|------|------|
| 用户 | 25 | 不同城市、不同兴趣的真实感用户 |
| 活动 | 55+ | 覆盖 12+ 城市、15+ 品类、线上线下混合 |
| 报名 | 自动模拟 | 各活动已有部分用户"报名参加"，看起来自然 |

### 活动品类

户外、音乐、读书、运动、美食、科技、舞蹈、桌游、艺术、公益、手工、电影、亲子、电竞

### 覆盖城市

北京、上海、广州、深圳、杭州、成都、西安、武汉、南京、厦门、苏州、三亚

## 快速开始

### 前置条件

1. 克隆并启动 yiyu-platform 后端（参见[主仓库 README](https://github.com/neko-huang/yiyu-platform)）
2. 确保后端运行在 `http://localhost:8000`

### 导入数据

```bash
# 安装依赖
pip install -r requirements.txt

# 导入所有模拟数据
python seed.py

# 清空已有数据后重新导入
python seed.py --reset

# 仅导入用户和活动，不模拟报名
python seed.py --no-participants

# 指定其他后端地址
python seed.py --base-url http://192.168.1.100:8000/api/v1
```

## 测试场景

### 1. 功能完整性测试

```
首页 → 查看活动列表、推荐区域
地图 → 查看活动标注（需配置高德地图 Key）
搜索 → 按关键词/分类搜索
活动详情 → 查看、报名
创建活动 → 填写表单、选位置、发布
个人中心 → 查看资料、编辑标签
```

### 2. 跨设备测试

- 在手机浏览器打开 `http://你的电脑IP:5173`
- 用不同账号登录，验证看到的活动一致
- 在一个设备创建活动，另一个设备刷新即可看到

### 3. 标签与推荐测试

- 编辑用户标签（如"户外"、"音乐"）
- 返回首页查看推荐区域是否匹配
- 搜索对应分类，验证结果正确

## 数据结构

- `users.json` — 用户数据（用户名、密码、标签、简介）
- `events.json` — 活动数据（标题、描述、坐标、分类、价格等）
- `seed.py` — 通过 API 自动导入的脚本
